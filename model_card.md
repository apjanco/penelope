# penelope-soc-v2

Fine-tuned [Qwen/Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B) for
stream-of-consciousness (SoC) detection and classification in literary texts.

Named after the final episode of Joyce's *Ulysses* — Molly Bloom's unbroken
interior monologue — the canonical example of stream of consciousness in fiction.

This is the second release. v2 adds a GRPO reinforcement-learning stage on top
of the v1 SFT adapter, using a large-model judge (Qwen3-235B-A22B) to reward
grounded, skeptical, and taxonomically precise reasoning traces. The primary
improvement over v1 is in type classification: the harder and more analytically
useful of the two subtasks.

## Model description

Given a prose passage, the model returns structured JSON identifying SoC
instances, their primary type from a ten-class taxonomy, and supporting textual
evidence. Each prediction is preceded by a `<think>…</think>` reasoning trace
that quotes the passage, names candidate types, and argues for the chosen label.

The taxonomy synthesises Robert Humphrey (1954) and Erwin R. Steinberg (1973):

| Type | Description |
|---|---|
| `direct_interior_monologue` | Unmediated first-person thought; no narrator frame |
| `indirect_interior_monologue` | Third-person syntax, character's diction; free indirect discourse |
| `omniscient_description` | Narrator describes psychology from outside with authority |
| `free_association` | Logic-defying leaps via sensory, phonetic, or emotional links |
| `orthographic_marker` | Italics, missing punctuation, or typography signals consciousness |
| `imagery` | Dense sensory language where perception *is* the consciousness |
| `simulation_state_of_mind` | Syntax/rhythm formally enacts an emotional state |
| `reverie_fantasy` | Character constructs an imagined scene; future/conditional diction |
| `hybrid` | Passage shifts between two or more types |
| `other_soc` | Recognised technique not captured above |

## Training

Training proceeded in two stages.

### Stage 1 — Supervised fine-tuning (SFT)

**Method:** QLoRA fine-tuning with a `ThinkMaskingCollator` that masks
`<think>…</think>` tokens from the loss so that only the structured JSON output
tokens receive gradient signal.

**Hyperparameters:**
- LoRA rank: 64, alpha: 128, dropout: 0.05, target modules: all attention and MLP projections
- Epochs: 3, batch size: 2, gradient accumulation: 8 (effective batch 16)
- Learning rate: 2e-4 with cosine decay
- Max sequence length: 4096
- Hardware: A100 80 GB

**Training results:**

| Epoch | Train loss | Eval loss |
|---|---|---|
| 1 | — | 0.0272 |
| 2 | — | 0.0252 |
| 3 | 0.0922 | 0.0272 |

### Stage 2 — Reinforcement learning from an interpretive judge (GRPO)

**Method:** Group Relative Policy Optimization (GRPO). For each training
passage the model generates eight candidate responses; a judge model scores
all eight and the policy is updated to favour higher-scoring responses.

**Judge:** Qwen3-235B-A22B, served as a local vLLM endpoint on a separate
compute node.

**Reward function** (weighted blend):

| Component | Weight | Measurement |
|---|---|---|
| Grounding | 20% | Quoted phrases appear verbatim in the source passage |
| Skepticism | 20% | Reasoning trace considers and rules out alternative types |
| Specificity | 20% | Reasoning uses precise taxonomy terms |
| Type coherence | 40% | Judge assesses whether the chosen label fits the passage |

Grounding and specificity are computed automatically (string matching); skepticism
and type coherence require a judge inference call.

**Checkpoint used:** `checkpoint-4762` (4 762 GRPO update steps).

**Hardware:** A100 80 GB.

### Dataset

Silver labels generated by four frontier LLMs (gemini-3-pro-preview, gpt-5,
mercury-2, qwen3-max) on 31 SoC literary works, merged under a conservative
consensus filter, plus 53 Project Gutenberg negative examples
(externalized-narration novels).

| Split | Examples |
|---|---|
| Train | 4 762 |
| Val | 594 |
| Test | 594 |

## Evaluation

Evaluated on the held-out test split (594 examples). Results compared against
the v1 SFT-only checkpoint.

**Binary SoC detection** (does the passage contain SoC?):

| | Precision | Recall | F1 |
|---|---|---|---|
| SoC — v1 (SFT) | 0.195 | **1.000** | 0.326 |
| SoC — v2 (GRPO) | 0.185 | 0.982 | 0.312 |
| Non-SoC — v1 (SFT) | 1.000 | 0.060 | 0.113 |
| Non-SoC — v2 (GRPO) | 0.818 | 0.019 | 0.036 |

Both versions have a high false-positive rate. v2 has slightly lower binary F1
(31.2% vs 32.6%) due to a modest drop in recall; the core false-positive bias is
not resolved by GRPO alone and remains the primary known limitation.

**Type classification** (all 594 examples, 16-class):

| Metric | v1 (SFT) | v2 (GRPO) | Δ |
|---|---|---|---|
| Weighted F1 | 3.10% | **3.78%** | +0.68 pp |
| Macro F1 | 3.27% | **3.92%** | +0.65 pp |
| Accuracy | 6.90% | **8.89%** | +1.99 pp |

Classes improved in v2: 6. Classes regressed: 0. Classes unchanged: 10.

Notable per-class gains:

| Type | v1 F1 | v2 F1 | Support |
|---|---|---|---|
| `direct_interior_monologue` | 12.5% | 18.2% | 30 |
| `omniscient_description` | 2.4% | 6.7% | 8 |
| `indirect_interior_monologue` | 21.4% | 22.2% | 62 |
| `reverie_fantasy` | 9.5% | 10.0% | 3 |

## Limitations

- **False-positive bias:** The model defaults toward predicting SoC; precision
  on the non-SoC class is low. Post-hoc confidence thresholding or a secondary
  filtering step is recommended for precision-sensitive applications.
- **Rare-class coverage:** Several taxonomy types (`free_association`,
  `hybrid`, `orthographic_marker`, `simulation_state_of_mind`) have near-zero
  F1 due to very low support in the test set.
- **Silver-label ceiling:** Training labels were generated by frontier LLMs
  under a consensus filter, not by literary scholars. The model's judgments
  reflect patterns in that silver data.
- **English literary prose only:** The model was trained and evaluated
  exclusively on English-language literary fiction.

## Intended use

This model is intended as a tool for computational literary analysis —
specifically for researchers studying stream-of-consciousness technique across
a corpus. It is not a general-purpose text classifier. Outputs should be
treated as interpretive hypotheses, not ground-truth labels.

## Limitations

- **v1 / research model.** Trained on a small silver-label corpus; expect
  further iterations to improve precision and type-classification accuracy.
- **High false-positive rate.** The model is biased toward predicting SoC.
  Post-hoc confidence thresholding or a secondary filtering step is recommended
  for precision-sensitive applications.
- **English modernist canon bias.** Training corpus is dominated by Joyce,
  Woolf, Faulkner, Richardson, and contemporaries. Performance on other
  traditions, languages, or periods is untested.
- **Thinking mode required.** The model was trained with Qwen3's
  `<think>…</think>` chain-of-thought enabled. Disabling thinking may degrade
  output quality.

## Usage

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("apjanco/penelope-soc-v1")
tokenizer = AutoTokenizer.from_pretrained("apjanco/penelope-soc-v1")

messages = [
    {"role": "user", "content": "Source: Mrs Dalloway\n\n<passage text>"},
]
text = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True, enable_thinking=True
)
inputs = tokenizer(text, return_tensors="pt")
outputs = model.generate(**inputs, max_new_tokens=4096, temperature=0.6, top_p=0.95)
print(tokenizer.decode(outputs[0][inputs.input_ids.shape[1]:], skip_special_tokens=True))
```

For batch inference over a corpus, use the
[Penelope pipeline](https://github.com/apjanco/penelope).
